## 서사·테마 저작 규약 (scene-log)

- **내용 1줄은 INDEX 헤드로 별도 승격되며 support에 자동 결박되지 않는다** —
  supported 원장과 대조한 영상 단위 개요만 쓴다(첫 체크포인트 폴백이 요약
  행세하지 않게 서사 미작성 상태를 방치하지 말 것).
- 서사 픽션이 완결(결말 커버)이면 `## 테마`(가치–기제–결과+명제 1줄)를
  추가하되, **기제 축이 원장의 구체 사건을 인용하지 못하면 저작 금지**
  (범용 명제 방지 — 결과 축 근거가 없으면 억지로 채우지 말 것).

이 절은 **비디오 위키 패턴**의 스키마 계층이다(공개 구현 경계=
`docs/ARCHITECTURE.md`). 3계층: **원장** = 영상+checkpoints.jsonl
(append-only)+image-provenance / **위키(에이전트 유지)** = `va wiki`가
재생성하는 `va-out/wiki/`(엔티티 페이지·태그 역색인·관계 원장+mermaid
그래프·대사록) / **schema** = 이 절. 후속 질의는 위키·원장을 먼저 보고,
저장된 근거가 부족할 때만 원본을 국소 재검증한다.

- **사람 표시 계층 규약**: 옵시디언 표면은 사람이 시각적으로 읽는 계층이다 — 파생 뷰의 1급 표면은 **사람 언어**(표시명=원제목·상태=한글·요약 1줄)로 쓰고, 기계 키(디렉터리명·ID·기계 상태값)는 링크 경로와 JSON에만 남긴다. 기계 키 자체는 불변(변경=링크·캐시 파괴). URL ingest는 원제목을 manifest `title`로 저장한다.
- **라벨 명명 규약(기본형 원칙)**: 라벨은 역할·목적이 드러나는 **기본형 명사**만 쓴다 — 수식어("수행"·"웅크린")·상태·가변 숫자("1818"·"4인")·매체어("오버레이"·"UI")·버전 접미("v2"류)를 라벨에 붙이지 않는다. 그런 정보는 `basis`·`situation`·`tags`·faces의 몫이다.
- **엔티티 등재 게이트(durable-only)**: `entities`/`speakers` 라벨은 **재등장 가능 자산**(인물·코너·포맷·반복 오버레이)이나 실제 질의 대상만 올린다 — 1회성 시각 요소·소품은 엔티티로 만들지 말고 체크포인트 `situation`·`tags`로만 남긴다. 위키 인덱스는 재사용 신호(재등장·관계·대사·실서술) 없는 엔티티를 "후보" 섹션으로 분리 표시하니, 세션 시작 시 후보를 승격(서술·관계 추가)하거나 방치(자연 강등)로 판단하라.
- **라벨링(추출 확장)**: 큐브릭 루프에서 verified/corrected 승격 시 체크포인트에 함께 기록한다:
  - `tags` — 모드별 권장 세트(자유 확장 허용, 변별력이 목적이므로 편당 과남발 금지):
    | 모드 | 권장 태그 세트 |
    |---|---|
    | 발화 주도 | 콜아웃 · 클러치 · 티키타카 · 정보전달 · 리액션 · 결론 |
    | 시각 주도 | 리액션 · 벌칙 · 슬랩스틱 · 자막드립 · 리빌 · 몽타주 |
    | 무발화 | 비주얼임팩트 · 전환 · 리빌 · 안무 · 엔드카드 |
    | 텍스트-온-스크린 | 사연 · 반전 · 훅 · 정보 · CTA |
    | 루프 모션그래픽 | 태깅 생략 (변별 정보 없음) |
  - `camera-*` 태그(모드 직교 축) — 샷 크기 `camera-클로즈업|미디엄|와이드` · 무빙 `camera-고정|팬|줌|핸드헬드`. **프레임에서 판독이 확실한 체크포인트에만** 부여(추정 금지) — 리프레이밍 ROI 선정·공간 방향 판정(카메라 기준)·컷 선정의 결정 신호가 된다
  - `quotes` — `[{"t": 12.4, "speaker": "진행자", "text": "…"}]`: 내용 이해에 중요한 대사만(전사 복붙 금지, 편당 3~10개)
  - `relations` — `[{"s": "진행자", "p": "벌칙 부과", "o": "멤버A"}]`: 인과·상호작용 엣지, p는 능동태 서술어. **관계 우선 규약**: verified 승격 시 버스트·사건의 **원인→결과 쌍**과 재등장 인물 간 상호작용을 우선 기록하라 — 단 억지 최소치 금지, 실제 인과·상호작용이 있을 때만(질의 가치의 최대 지분은 관계층이다)
  - `arc` — `"기"|"승"|"전"|"결"`: 수렴 후 각 체크포인트의 서사 위치 라벨(쇼츠·루프 모션그래픽은 생략 가능) — scene-log 표에 기승전결 열로 렌더된다
- **scene-log 서사 블록**: 장면 로그(`<ws명>.md`)의 `tca:narrative` 블록(내용·전개·기승전결)은 재생성에도 보존된다 — 수렴 후 **내용 1~3줄, 전개 서술, 기승전결 각 1줄**을 작성하라. 문서 위계는 콘텐츠(대분류) → 장르·키워드(frontmatter mode·tags·keywords) → 내용 → 전개 → 기승전결 → **3요소 신호(화면=scenes·조망 / 소리=발화율·버스트 / 서사=체크포인트·arc)** → 장면 표(원장) → 근거 프레임 순 — 결정적 요약이 디테일보다 앞(BLUF). **내용 1줄은 INDEX의 라우팅 헤드로 별도 승격되며 아직 claim-level support에 자동 결박되지 않는다.** 영상 단위 개요로 쓰되 supported 체크포인트와 다시 대조하라(장면 단위 서술 금지).
- **위키 빌드**: 세션 종료 시 `va index && va wiki`. 기본 semantic projection은 `verified`/`corrected`이면서 현재 해소 가능한 support가 있는 체크포인트만 root INDEX·scene-log frontmatter·active wiki에 승격한다. 시각 support는 decode 가능한 파일뿐 아니라 추적된 provenance와 체크포인트에 겹치는 시점이 필요하고, 전사 support는 실제 segment ID와 시간 겹침이 필요하다. support가 없는 terminal과 `hypothesized`는 원장·상세 장면표·검색에는 남지만 active entity/tag/relation/quote에는 들어가지 않는다. 기존 전체 상태 집계를 재현해야 할 때만 `va wiki --include-hypotheses`를 명시한다. 기본 재빌드에서 승격 해제된 생성 엔티티 페이지는 notes와 정체성을 보존한 채 `wiki/hypotheses/entities/`로 격리된다. 위키는 결정적 집계(placement) — 라벨의 의미 판단(selection)은 기록 시점의 네 몫이다.
- **서술 블록**: 엔티티 페이지의 `<!-- tca:notes:start/end -->` 블록은 재생성에도 보존된다 — 다각 관점 종합(역할 변화·명장면·시리즈 맥락)과 **모순 플래그**(새 영상이 기존 서술과 어긋나면 `⚠ 모순:` 줄 추가)를 여기에 쓴다. 블록 밖 수기 수정은 재생성 시 소실된다.
- **질의 라우팅(index-first)**: 코퍼스 질의는 ①`va-out/INDEX.md`·`wiki/INDEX.md` → ②해당 페이지 드릴다운 → ③부족하면 `va search` → ④그래도 부족할 때만 워크스페이스 프레임 재검증. 임베딩·재시청 없이 위키가 1차 지식베이스다.
- **크로스 비디오 인지**: 새 영상 분석 시작 전에 화자 라벨을 wiki/entities에서 먼저 찾아 재등장 인물이면 기존 페이지 맥락을 이어받는다(시리즈 연속성). **재등장 대상의 라벨은 기존 페이지 표기를 정본 그대로 재사용** — 새 변형 표기 금지, 부가 정보는 basis에 넣는다(표기 변형이 크로스 비디오 인지율을 직접 깎는다). 위키 인덱스의 "통합 후보" 섹션이 변형 의심을 자동 표면화하니 세션 시작 시 병합을 판단하라. 인물 라벨은 화면 내 시각 단서 기반 유지 — 실명 추정 금지는 위키에서도 동일.

## 사람 표면 용어 맵 (표시 계층 전용 — 기계 값·원장 불변)

산출물(장면 로그·스틸 목록·INDEX·위키)의 표면은 영상업계 어휘를 쓴다.
기계 계약(frontmatter 키·상태 코드·앵커·JSON·캐시 파일명)과 CLI(에이전트
조작면)는 치환하지 않는다 — 스킬 어휘와 도구 출력의 결합이 분석 성능
계약이다. 정본 맵: `corpus_projection.STATUS_KO·READINESS_KO·human_reason`.

| 기계 용어 | 사람 표면 |
|---|---|
| verified / corrected / hypothesized | 확인 / 정정 / 추정 |
| converged / cover_gaps / verify_more | 완결 / 공백 남음 / 검증 더 |
| scenes(장면전환) | 컷 전환 N회 |
| highlights(버스트) | 오디오 피크 N곳 |
| filmstrip | 조망 시트 |
| frame / frame-crop | 스틸 / 부분 스틸 |
| capture reason 소인 | 촬영 사유(한글 맵, 미등록 소인은 원문 유지) |
| cause-해시 | 사람 표면 비노출(출처 원장 전용) |
| legacy-untracked | 출처 기록 없음(초기 수집분) |
